# 気体分子運動論ボルツマン分布シミュレーター

多数の気体分子をシミュレーションし、速度分布（マクスウェル-ボルツマン分布）をリアルタイム可視化するツール。

## 機能

- Canvas 600×400 に分子200個（半径4px）をシミュレーション
- 初期速度はマクスウェル-ボルツマン分布に従うランダム値
- 境界弾性反射（壁衝突）
- 分子間衝突（近距離で速度交換・重なり解消）
- 温度スライダー（50K〜2000K）→速度スケーリングで平均速度変化
- 速度分布ヒストグラムをCanvas下部にリアルタイム描画（理論曲線付き）
- 温度・平均速度・壁衝突数（圧力）の数値表示
- requestAnimationFrame によるアニメーション
- 一時停止・リセットボタン

## 技術仕様

- バニラJS / Tailwind CDN / Canvas 2D API
- XSSガード: escHtml() 定義済み
- 全インタラクティブ要素に aria-label 付与
